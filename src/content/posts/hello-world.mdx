## 为什么搭建这个站点

这是一个用于记录思考、项目与生活的个人数字中台，使用 Next.js + MDX 构建。

## 技术选型

- **前端**：Next.js App Router + TypeScript + TailwindCSS
- **内容**：MDX 文件（博客/项目）
- **数据库**：PostgreSQL（动态数据）
- **AI**：Claude Opus 4.8

### 为什么选择 MDX

MDX 文件直接存储在 Git 中，SEO 友好，也更方便与 AI 协作管理内容。
